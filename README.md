# ✈️ Indian Airlines Analytics Dashboard

An interactive **Indian Airlines Analytics Dashboard** built using Microsoft Power BI to explore airline performance, passenger trends, ratings, passenger distribution, and estimated profit through dynamic visualizations.

## 📌 Project Overview

This project focuses on analyzing Indian airline data and presenting meaningful insights through an interactive Power BI dashboard.

The dashboard allows users to explore different airlines, compare performance metrics, identify passenger trends, and understand airline-wise distributions using interactive filters and visualizations.

Users can select individual airlines, including Air India, IndiGo, Akasa Air, SpiceJet, and Star Air, to explore the available insights dynamically.

## 🎯 Project Objectives

- Analyze passenger distribution across different Indian airlines.
- Understand monthly passenger trends.
- Compare ratings across airlines.
- Visualize airline-wise passenger distribution.
- Explore estimated profit distribution.
- Develop an interactive dashboard for data exploration and analytical reporting.

## 🚀 Key Features

### 1. Interactive Airline Selection
- Select individual airlines to explore their data.
- Supports Air India, IndiGo, Akasa Air, SpiceJet, and Star Air.
- Dynamic filtering for airline-specific analysis.

### 2. Key Performance Indicators (KPIs)
- Passenger-related metrics.
- Airline performance indicators.
- Estimated profit metrics.

### 3. Data Visualizations

| Visualization | Description |
|---|---|
| Monthly Passenger Trends | Tracks passenger trends over time using a line chart. |
| Airline Ratings | Compares ratings across different airlines. |
| Passenger Distribution | Displays airline-wise passenger distribution using a bar chart. |
| Estimated Profit Analysis | Visualizes estimated profit distribution using a donut chart. |

### 4. Dynamic Dashboard
- Interactive filters and airline selection.
- Dynamic visualization updates.
- Multiple charts for comparative analysis.
- Easy exploration of airline-related metrics.

## 📊 Dataset Information

The project uses a large Indian airline dataset for dashboard development and data analysis.

The complete dataset is **not included in this public GitHub repository** for the following reasons:

- **Large File Size:** The dataset is relatively large and would unnecessarily increase the repository size.
- **Data Privacy:** The underlying dataset is kept separate from the public repository out of consideration for data privacy and confidentiality.
- **Data Sharing Considerations:** The complete dataset is not redistributed as part of this project.

**Important:** The repository includes the Power BI dashboard file and screenshots for demonstration purposes. The original dataset is not publicly distributed through this repository.

## ▶️ How to Explore the Dashboard

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop).
3. Open the `Airline_Analysis.pbix` file.
4. If the original dataset is unavailable locally, reconnect the appropriate data source and update the data paths.
5. Explore the dashboard using the available airline filters and visualizations.
