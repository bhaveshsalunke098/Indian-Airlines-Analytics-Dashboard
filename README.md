# ✈️ Indian Airlines Analytics Dashboard

An interactive Power BI dashboard designed to analyze Indian airline data through visualizations and key performance indicators. This project provides insights into passenger trends, airline performance, ratings, passenger distribution, and estimated profit.

## 📊 Project Overview

The Indian Airlines Analytics Dashboard provides an interactive way to explore airline-related data and understand different performance metrics.

The dashboard allows users to select individual airlines and dynamically explore visual insights through interactive filters and visualizations.

## 🎯 Project Objectives

- Analyze passenger distribution across different airlines.
- Explore monthly passenger trends.
- Compare airline ratings.
- Visualize airline-wise passenger distribution.
- Analyze estimated profit distribution.
- Build an interactive dashboard for data exploration and reporting.

## 🚀 Dashboard Features

### 1. Interactive Airline Selection
- Select individual airlines, including Air India, IndiGo, Akasa Air, SpiceJet, and Star Air.
- Explore airline-specific information using interactive filters.

### 2. Key Performance Indicators (KPIs)
- Passenger-related metrics.
- Airline performance indicators.
- Estimated profit metrics.

### 3. Data Visualizations
- **Monthly Passenger Trends:** Analyze passenger trends over time using a line chart.
- **Airline Ratings:** Compare ratings across different airlines.
- **Passenger Distribution:** Visualize passenger distribution using bar charts.
- **Estimated Profit Analysis:** Explore profit distribution through a donut chart.

### 4. Dynamic Dashboard
- Interactive airline selection.
- Dynamic visual updates.
- Multiple visualizations for easier comparison and analysis.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Data Analytics** – Data exploration and performance analysis.
- **Data Visualization** – Interactive charts, graphs, and KPI reporting.

The project uses an Indian airline dataset for analysis and visualization.

The complete dataset is not included in this repository because of its large file size.

**Note:** The dataset can be added separately if required. Please refer to the original dataset source for data access.

## ▶️ How to Explore the Dashboard

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open `Airline_Analysis.pbix` using Power BI Desktop.
4. Explore the dashboard and interact with the airline selection filters.
5. Analyze the available KPIs and visualizations.

**Note:** If the original dataset is not available locally, some visuals may require reconnecting the data source or updating the file path.
